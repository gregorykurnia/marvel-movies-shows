Marvel Directory · visual design v1

Comic-panel bright, modern clean.

Bold ink outlines, offset “pop” shadows, five bright hero colours on warm paper, and a halftone dot motif used sparingly. Every page — even the backup screen — uses the same panels, header and chips.

01

Colour

Five bright hero colours, each with a fixed job. Brights are for fills, bars and accents. Text on a bright fill uses the colour’s --on-* token; coloured text uses the --*-ink shade. Toggle the theme to see the dark set.

09

Rules at a glance

Full list in DESIGN_GUIDE.md. These are the ones that keep every page looking like the same app.

DOTokens only

Every colour, radius and shadow comes from a token. No raw hex values in components.

DOPage header on every page

Eyebrow + title + actions, with the section accent colour. Forms and error pages included.

DORed = movie, Blue = show, Orange = short

Everywhere: chips, kind bars, timeline pins. Never swap or reuse these for anything else.

DOMono for data

Years, S01·E01 codes, counts, universe designations always in JetBrains Mono.

DON’TWhite text on bright fills

Yellow, green, cyan and orange fills always take ink text (--on-*).

DON’TOverdo the comic

One primary button per view. Halftone and bursts are accents, not wallpaper.
